# Commercial license for Vanderwaals

## Dual licensing model

Vanderwaals is offered under a dual licensing structure:

1. **AGPL-3.0** for open-source and non-commercial community distribution.
2. **Commercial License** for proprietary, enterprise, or rebranded commercial distribution.

---

## When a commercial license is required

A commercial license is required if you:

- Distribute modified, closed-source, or rebranded versions of Vanderwaals.
- Integrate Vanderwaals source code into a proprietary application.
- Offer Vanderwaals or derivative works as a commercial network or SaaS service.
- Monetize derivative versions through paid app distribution, subscriptions, or advertising.
- Remove or modify original project branding, credits, or notices without publishing full source code.

---

## Open-source AGPL-3.0 terms

Under AGPL-3.0 (without a commercial license), you may:

- Use Vanderwaals for personal, educational, or research purposes.
- Inspect, build, and modify the source code for open-source projects.
- Share modifications under the same AGPL-3.0 license terms, provided complete source code is made available to network users.

---

## Commercial license rights

A commercial license provides:

- Right to distribute derivative works without source code disclosure.
- Right to integrate software into proprietary enterprise applications.
- Exemption from AGPL-3.0 network copyleft requirements.
- Commercial support and maintenance agreements (subject to license tier).

A commercial license does **not** grant:
- Rights to use the "Vanderwaals" trademark without explicit written permission (see [TRADEMARK.md](TRADEMARK.md)).
- Authorization to claim original primary authorship.
